# ナレーションを Kokoro + yomiscript に切り替える（#60）

## 目的

macOS の `say` はナレーションの漢字を読み間違える。読みを文脈から決めて発音記号（YomiScript）で書き、Kokoro にそのとおり話させる。

## 方針

- 読みは `packages/video/readings/<courseId>.json`。場面 id → 発話の配列（文ごとに一つ）。
  - 文ごとに分けるのは、一度に話す長さを抑え、発話の間に一定の間（`SENTENCE_GAP_SECONDS`）を入れるため。
- `packages/video/src/readings.ts` の `readingProblem` が、読みと台本の一致を確かめる。
  - パースできること。
  - `<t:…>` をつなげると台本と1文字も違わないこと。台本だけ直して読みを直し忘れると落ちる。
  - `<t:…>` が1語の長さに収まり、発音がその文字数より短くないこと。文全体に一つの短い読みを付けるような手抜きを防ぐ。
- `generate-voice.ts` は `say` をやめ、`openKatarite("kokoro")` で文ごとに話し、間をはさんでつなげ、48kHz の wav にする。読みが台本と合わなければ止まる。
- 読みは Claude のエージェントがコースごとに一語ずつ書く。
  - Codex に書かせた試作は、カタカナ語や漢字の発音が崩れていて使えなかった。
  - 確かめは、読みをかなに戻した一覧を Codex に渡して、読み間違いを指摘させる（Codex クロスレビュー）。
- 全コースの読みがそろったら、テストで全コースの一致を確かめ、音声と動画を作り直して Release を差し替える。
