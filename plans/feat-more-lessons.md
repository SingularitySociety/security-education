# 公開済みの8コースに授業を足す（#38・#18 の残りと、Codex の点検の分）

## 目的

既存コースに、被害のあとや最新の手口の授業を1〜3場面と問題2〜3問で足す。

| コース          | 足した授業                                                                                | issue |
| --------------- | ----------------------------------------------------------------------------------------- | ----- |
| patching        | 更新しても、もう入られているかもしれない／更新の前に備え、更新のあとも見る                | #38   |
| hiring-attacks  | 入社した直後は権限を小さく始める／採用した人が偽物だと分かったら                          | #38   |
| install-sources | いつもの更新で不正な版が届くことも／不正な版を入れてしまったら                            | #38   |
| passwords       | パスキーの登録を装う手口／許可なく私物の端末で仕事にログインしない／乗っ取りに気づいたら  | #18   |
| phishing        | 最初の「/」の直前がドメイン（「ん」の見せかけ）／乗っ取られた本物のアドレスから届くメール | #18   |
| smishing        | 税務署を名乗る偽アプリ／公的機関のアプリの入手先／QR コードの貼り替えと「返金」の QR      | #18   |
| home-network    | 家の機器が攻撃の中継点に／ルーターの画面で確かめること                                    | #6    |
| mfa-methods     | 頼んでいない回線の手続きの通知／番号を取り戻したら認証を立て直す                          | #6    |

## 方針

- 1コースずつエージェントが公的機関の情報で確かめて書き、Codex のクロスレビューを反映した。実在の企業名・事例名は使わず「報じられた例」とする。
- 新しいコースと重なるところは要点だけにし、「くわしくは別のレッスンで」とつなぐ。
- 読みを書き直し、動画を描き直す。どれも10分未満。
