# 公開済みコースに「被害のあと」の授業を足す（#38 の一部）

## 目的

Codex のカリキュラム点検で挙がった「既存コースに足したい授業」（#38 の優先度：高）のうち8つを、既存コースに1〜2場面と問題2〜3問で足す。

| コース             | 足した授業                                                         |
| ------------------ | ------------------------------------------------------------------ |
| phishing           | 開いてしまった・入力してしまった後                                 |
| smishing           | 偽アプリを入れてしまった後                                         |
| phone-scams        | 遠隔操作を許した後の初動                                           |
| outside-work       | 紛失した端末が見つからないとき                                     |
| data-disposal      | クラウド・SaaS の契約終了時に何を消すか                            |
| account-lifecycle  | 退職・異動・委託終了を一枚のチェックリストに、止め忘れに気づいたら |
| boss-impersonation | 口座の変更は二人で確かめる、振り込んでしまったら                   |
| ai-data-and-tools  | AI の答え・生成コードを使う前の確認、確かめずに使ってしまったら    |

## 方針

- 「止める・知らせる・残す・変える」の順番で、具体的な行動を書く。会社の場合と個人の場合を書き分ける。
- 新しいコースと重なるところは要点だけにし、「くわしくは別のレッスンで」とつなぐ。
- 1コースずつエージェントが公的機関の情報で確かめて書き、Codex のクロスレビューを反映した。既存部分への「高」の指摘も、範囲内で直せるものは直した。
- 読みを書き直し、動画を描き直す。どれも10分未満。
