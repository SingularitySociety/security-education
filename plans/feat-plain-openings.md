# 動画だけで前提が分かるように、コースの冒頭を書き直す

## 目的

動画だけを見た人が、何を学ぶのか、その手口や被害がどこにどうやって届くのかを、最初につかめるようにする（#124、#125）。

## 基準

- 家庭・一般向け（はじめての人へ、まず押さえる基本、乗っ取りと情報漏えい、電話やメッセージの詐欺、もうけ話・仕事・買い物の詐欺、身の安全と家族、家庭、AI を使うとき）は、予備知識のない人にも分かる書き方にする。
  1. 最初に、このレッスンで何を学ぶかを言う。
  2. タイトルのすぐ後に、架空の一人の具体的な場面で、どこにどうやって届くかを見せる。
  3. 用語は使う前に、身近なたとえで説明する。一文を短く。
  4. 被害にあったか・あいそうかを見分ける手がかりを入れる。
- 会社・エンジニア向けは標準の書き方でよい。Codex の点検で指摘のあった backup-recovery と forensics の冒頭を直す。
- 動画は10分を超えてもよい。内容を優先する（目安12分程度）。

## 進め方

- Codex に全73コースの冒頭を点検してもらった。判定が甘かったため、家庭・一般向けは全コースを書き直した。
- エージェント1つにつき3コースを担当（ファイル単位で重ならない）。各コースを公的機関の情報で確かめ、Codex でレビューし、読みも Codex で見直した。
- 書き直しの途中で Codex が指摘した、既存の記述の安全・正確さの問題（つきまといのタグの扱い、相談先の書き分け、法律の要件、報告の期限など）も直した。
- 読みの誤りを全コースで洗い出して直した（裏面、作業、手がかり、応じず など）。「〜疲れ」は連濁で「づかれ」にそろえた。
