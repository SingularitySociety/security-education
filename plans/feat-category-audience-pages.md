# カテゴリーのページと、対象別のページ

## 目的

カテゴリーごと、対象ごと（家族に送る用、中小企業用）に、そのまま人に送れるページを作る（#120）。

## 方針

- カテゴリーのページ `/categories/<id>/`: カテゴリーのコースだけを並べる。トップのカテゴリーの見出しからつなぐ。
- 対象別のページ `/for/<id>/`: 内容は `packages/course/src/audiencePages.ts`。はじめに、送るときの文面（送る・文面とリンクをコピー・リンクだけコピー）、見る順に並べたコース、あわせて確かめるチェックリストの項目。トップの最初に入口を置く。
  - 家族: 止まって相談 → 電話とメッセージの詐欺 → お金をだまし取る誘い → 家族で決めておくこと。
  - 中小企業: 社員全員 → 経営者・管理担当 → IT担当。受講の記録はブラウザに保存され、サイトから会社に送られないことを書く。
- どちらのページも、ビルド時に HTML・共有用の画像・JSON-LD（ItemList）を書き出す。
- コースのカードは `CourseCard.vue` に切り出し、トップ・カテゴリー・対象別のページで使う。
- 文面は Codex でレビューし、指摘（記録の扱いの言い切り、家族向けの文面の不安のあおり方、全社員向けに事故の初動を入れる、など）を反映した。
