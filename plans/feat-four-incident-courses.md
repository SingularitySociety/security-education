# 事故と漏えいのコース4本の公開（#69 #70 #71 #72）

## 目的

委託先経由の侵害、ランサムウェアの暗号化前の兆し、漏えいを知らされた個人の二次被害防止、会社の報告・本人通知・公表を、動画つきで一覧に出す。

| id                           | 題材                                   | カテゴリー       |
| ---------------------------- | -------------------------------------- | ---------------- |
| supply-chain-breach          | 委託先・クラウドを経由する侵害         | 中小企業の管理   |
| ransomware-before-encryption | ランサムウェアの暗号化前に気づく       | 事故が起きたとき |
| after-data-leak              | 漏えいを知らされたあとの二次被害を防ぐ | まず押さえる基本 |
| incident-reporting           | 報告・本人通知・公表                   | 事故が起きたとき |

## 方針

- 1本ずつエージェントが公的機関・一次情報（個人情報保護委員会のガイドライン、警察庁、IPA、JPCERT/CC、国民生活センター、CISA など）で確かめて書き、Codex のクロスレビューを反映した。
- 既存の初動・バックアップ・委託先のコースと重ならないよう焦点を分けた。after-data-leak（個人の側）と incident-reporting（会社の側）も分けた。
- 読みは `readings:check` と Codex のカナ表記レビューを通す。動画はそれぞれ10分未満。
