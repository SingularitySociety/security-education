# 新しいコース9本の公開（#88〜#96）

## 目的

既存コースを全文検索して見つけた抜けと、ユーザーの提案（ブラウザの拡張機能）を、動画つきで一覧に出す。

| id                   | 題材                                                 | カテゴリー           |
| -------------------- | ---------------------------------------------------- | -------------------- |
| tracking-stalkerware | 位置情報の追跡アプリと紛失防止タグによるつきまとい   | まず押さえる基本     |
| sextortion           | 性的な画像を使った脅しと画像の拡散                   | 家庭で気をつけること |
| digital-legacy       | 亡くなった家族のアカウントとデジタル遺品、自分の備え | 家庭で気をつけること |
| secrets-in-code      | API キーやパスワードをコードに残さない               | 開発者向け           |
| protect-parents      | 離れて暮らす親を詐欺から守る                         | 家庭で気をつけること |
| browser-extensions   | ブラウザの拡張機能は「金庫の鍵」を預けるもの         | まず押さえる基本     |
| fake-billing         | 架空請求・ワンクリック請求・当選の知らせ             | 電話やネットの詐欺   |
| p2p-trade-scams      | フリマ・チケットなど個人間取引の詐欺                 | 電話やネットの詐欺   |
| fake-job-offers      | 就職・転職活動中の人を狙う偽の求人                   | 電話やネットの詐欺   |

## 方針

- 1本ずつエージェントが公的機関・一次情報で確かめて書き、Codex のクロスレビューを反映した。
- tracking-stalkerware と sextortion は、被害にあった人の安全と相談しやすさを最優先にし、悪用できる手順や性的な描写は書かない。
- チェックリストの拡張機能の項目から、browser-extensions へもリンクする。
- 読みは `readings:check` と Codex のカナ表記レビューを通す。動画はそれぞれ10分未満。
