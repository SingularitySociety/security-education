# 描き出しの一時フォルダを、使い終わったら消す

## 目的

動画・共有画像の描き出しが、Remotion の一時フォルダ（`public/` の全ナレーション音声の複製、1回 約3.7GB）を残し続け、ディスクを使い切った（#127）。

## 方針

- `packages/video/scripts/bundle.ts` の `withBundle` で、一時フォルダを作って仕事をさせ、終わったら（失敗しても `finally` で）消す。
- `render-all.ts` と `render-og.ts` はこれを使う。
- 共有画像を1枚描き出し、前後で一時フォルダが残っていないことを確かめた。
