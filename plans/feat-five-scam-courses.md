# 詐欺と乗っ取りのコース5本の公開（#63 #64 #65 #66 #68）

## 目的

Codex と web で調べた手口・対策・被害のあとの手順をもとに書いたコースを、動画つきで一覧に出す。

| id                         | 題名の題材                                     | カテゴリー         |
| -------------------------- | ---------------------------------------------- | ------------------ |
| financial-support-takeover | 金融機関のサポートを装う乗っ取り               | 電話やネットの詐欺 |
| realtime-phishing          | QR コード・検索広告・中継型のフィッシング      | まず押さえる基本   |
| investment-romance-scams   | SNS 型投資・ロマンス詐欺と「送金役」           | 電話やネットの詐欺 |
| fake-side-jobs             | 偽の副業・在宅ワークと闇バイトの入口           | 電話やネットの詐欺 |
| email-takeover-abuse       | 乗っ取られたメールの転送・請求書・連絡先の悪用 | 事故が起きたとき   |

## 方針

- 1本ずつエージェントが公的機関・一次情報で事実を確かめて書き、Codex のクロスレビューを反映した。
- 既存コースや同時に書いたコースとの重なりを避けるよう、それぞれの焦点を分けた（例: 中継型の流れは金融機関のコースで扱い、フィッシングのコースは QR コードと検索広告に寄せた）。
- 読みは `readings:check` と Codex のカナ表記レビューを通す。
- `courses` に登録し、`yarn video:voice` → `yarn video:render` で描き出す。動画はそれぞれ10分未満。
- README の表は `videoDurations.json` から作り直す。mp4 は Release `videos` に添付する。
