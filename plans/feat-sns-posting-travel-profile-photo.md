# SNS の発信コースに、旅行中の投稿・プロフィール情報・写真の位置情報を足す（#18 の一部）

## 目的

ユーザーの提案（#18 のコメント）を sns-posting に場面として足す。

- 旅行中・出張中はリアルタイムに投稿しない（留守、家族を狙う詐欺の電話、搭乗券などの写り込み、会社の場合は出張先や商談）
- 誕生日・出身校・ペットの名前・旧姓は、秘密の質問や本人確認、パスワードの推測の手がかりになる
- 写真のファイルに撮影日時・機種・位置情報が入ることがある

## 方針

- 場面 `photo-data` / `travel-post` / `profile-info` を足し、問題も足す。前からある関連の一文は新しい場面へ移す。
- 10分未満に収めるため、ほかの場面の言い回しを詰める。
- Codex のクロスレビューで「高」とされた二点（誹謗中傷の定義が「嘘なら駄目」と読める、災害時は真偽の確認より避難が先）も直す。
- 読みを合わせて書き直し、動画を描き直す。
