# feat: 確認テストを問題プールからランダムに出題する

## ゴール

再受験で答えを覚えてしまわないようにする。

## 方針

- `Course.quiz` を `Course.questionPool` に改名し、各コースの問題を増やす
- `packages/course/src/drawQuiz.ts`（純粋関数、乱数は引数で受け取る）
  - `shuffled`: 各要素に乱数のキーを付けて並べ替える
  - `drawQuiz`: プールを混ぜて `QUIZ_QUESTION_COUNT` 問を取り、各問の選択肢も混ぜる
- 試験画面は表示時と再受験時に引き直す。採点は選択肢の id で行うので、並べ替えの影響を受けない
- テスト: 固定シードの乱数で何度も引き、全問が出ること・正解の位置が動くこと・プールの大きさ・
  解説が選択肢の記号を指していないことを確認する
