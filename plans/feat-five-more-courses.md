# 通販・スマホ決済・外から見える入口・DDoS・AI エージェントのコース5本の公開（#81〜#85）

## 目的

Codex のカリキュラム点検（#6）で挙がった候補を、動画つきで一覧に出す。

| id                   | 題材                                      | カテゴリー                |
| -------------------- | ----------------------------------------- | ------------------------- |
| shopping-site-scams  | 悪質な通販サイトと非対面取引の詐欺        | 電話やネットの詐欺        |
| mobile-apps-payments | スマホの不正アプリと決済の不正利用        | まず押さえる基本          |
| exposed-entry-points | VPN・リモートアクセスなど外から見える入口 | 情報システム担当の基本    |
| ddos-continuity      | DDoS 攻撃を受けたときの事業継続           | 情報システム担当の基本    |
| ai-agents-at-work    | AI エージェントに仕事を任せるとき         | AI と開発ツールを使うとき |

## 方針

- 1本ずつエージェントが公的機関・一次情報で確かめて書き、Codex のクロスレビューを反映した。
- 既存コースと重ならないよう焦点を分けた（例: ai-agents-at-work は任せ方・権限・承認・記録に絞り、入力する情報とプロンプトインジェクションは既存コースに任せた）。
- 読みは `readings:check` と Codex のカナ表記レビューを通す。動画はそれぞれ10分未満。
